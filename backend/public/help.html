Homepage Route

Home page with base route: /api/v1 – Shows welcome or API root page.


Home page: / – Shows welcome or API root page.

Routes Overview

- Get a joke by tags • GET: ${baseRoute}/joke?tags=tag1&tags=tag2
- Get all jokes with optional tags • GET: ${baseRoute}/jokes?tags=tag1&tagNames=tag2
- Get all tags • GET: ${baseRoute}/tags
- Get joke by ID • GET: /api/v1/j/:id (Public / User)
- Full update joke • PUT: /api/v1/j/:id (Admin only)
- Partial update joke • PATCH: /api/v1/j/:id (Admin only)
- Delete a joke • DELETE: /api/v1/j/:id (Admin only)

POST /joke Body Format 

        {
  "joke": "Why did the chicken cross the road?",
  "tags": ["animal", "classic"],
  "rating": 4.5
}

Pagination Support

Use page and limit query parameters with jokes endpoint: 

        GET ${baseRoute}/jokes?page=2&limit=10

This returns the second page of jokes with 10 items per page.
